# 原文跟随播放

有匹配时间轴时，原文按播放器的实际媒体位置标记当前段落。播放或进度跳转使当前段落离开可视区域时，页面定位到该段；暂停保留标记。手动触碰原文、滚动或选词后进入自由阅读，点击“回到当前播放”恢复跟随。变蓝只是临时显示，不写入用户高亮记录。

英文和中文保留整篇原生文本选择；双语仍按语言段选择。现有段落 ID、内容哈希和用户高亮位置不变。复盘卡片、答案和评分不参与时间定位。

`app/src/main/assets/transcript-timelines.json` 只含时间和哈希，不含原文或音频。它绑定现有资料包的音频 SHA-256 和有序双语段落内容哈希，因此旧资料包无需重新导入。音频、原文或时长不匹配时，继续使用普通阅读，不能套用别的版本时间轴。

生成命令：`python tools/build_transcript_timelines.py`。默认读取本地三份原始 ZIP 和现有 V4 测试资料包；也可通过 `--sources`、`--packs`、`--output` 指定路径。生成过程不修改资料包、原文、音频、答案或评分数据。

当前 272 个 Part 均可绑定。3 个 Part 的源区间有重叠，保留源坐标并以较晚开始的段落优先；标题和未收录的音频提示不标为正在朗读的段落。时间轴来自原资料，结构与哈希校验不代表逐词声学对齐。

4 个 Part 的源时间尾端比 MP3 长约半秒。运行时允许最多 1 秒的尾部余量，仅将结束时间限制到播放器实际时长，不改变起点或丢弃整段；更大的时长差异停用同步。原始时间轴文件不因此改写。
